介護に関する入門的研修 理解度チェック：Android通信改善版

■変更内容
- 研修一覧・問題・採点結果・講師集計などのGET通信を、同一サイト内のNetlify Function経由に変更。
- Netlify FunctionがGASのJSONP応答を受け取り、JSONP形式に整えてブラウザへ返します。
- 回答送信（POST）は、既存のGAS直送信方式を維持しています。今回確認できていないPOST経路を変更してリスクを増やさないためです。
- GASコードとスプレッドシートの構成は変更していません。

■ファイル
- index.html
- netlify/functions/gas.js
- netlify.toml

■公開前の注意
このパッケージは未公開です。Netlifyへアップロードする前に、Netlify Functionsが有効なサイトであることを確認してください。
この環境ではNetlify本番環境への接続テストは実施できていません。したがって、Androidでの解消を保証するものではありません。
現在の公開サイトのバックアップを保存してから、ZIP内の3点をまとめて一度だけデプロイしてください。
GAS側の再デプロイは不要です。

■重要
GASの管理パスワードが初期値のままなら、本番利用前に変更してください。
